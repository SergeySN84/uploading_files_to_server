# MyProject — Backend & Frontend Tests

Проект демонстрирует реализацию тестов для backend (Django/DRF) и frontend (Selenium WebDriver) с использованием Poetry и Docker.

---

## 🛠️ Технологии

- Python 3.10+
- Django + DRF
- pytest + pytest-django
- Selenium WebDriver (Python)
- Poetry (менеджер зависимостей)
- Docker & Docker Compose
